# OMake

**OMake** is a scalable build system created by Jason Hickey and Aleksey Nogin
at Caltech in the early 2000s to build large OCaml projects like MetaPRL and the
Mojave compiler. It pairs make-style rules with a full functional scripting
language and content-signature-based (MD5) dependency tracking, and it saw real
external adoption across the OCaml community. It remains available via opam.

**Status: this repository is Jason Hickey's fork of the community-maintained
OMake** (continued by Hongbo Zhang and Gerd Stolpmann; upstream at
[github.com/ocaml-omake/omake](https://github.com/ocaml-omake/omake) and
[projects.camlcity.org](http://projects.camlcity.org/projects/omake.html)),
pinned at v0.10.2 (2017). For current releases and active maintenance, use the
upstream project — this fork is preserved for historical continuity within the
MetaPRL ecosystem.
